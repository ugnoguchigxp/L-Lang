# テトリスの生成依頼

日本語の単独ブラウザアプリ「月夜のテトリス」を作る。10列×20行の盤面、I/O/T/S/Z/J/Lの7種類、時計回り・反時計回りの回転、左右移動、ソフトドロップ、ハードドロップ、自然落下、ゴースト、次のブロック、一時停止・再開、新しいゲームを提供する。キーボードと画面上のボタンで操作できる。

ゲームはL-LangのJSON SemanticIRを正本とし、Wasmでルール、盤面、ブロックの選択、得点、ライン数、レベル、終了判定、表示データと落下間隔を計算する。TypeScriptにゲームロジックを書いたり、TypeScript経由でIRを作ったりしない。乱数は入力seedから決定的に計算し、7-bagで全種類を一巡させる。1/2/3/4ライン消去は100/300/500/800×消去前レベル、ソフトドロップは1点/行、ハードドロップは2点/行。10ラインごとにレベルが上がる。回転は単純な横キック（0,-1,1,-2,2）を使い、完全なSRS・ホールド・T-spin・対戦機能は対象外。

JavaScriptは共通テンプレートの入力・タイマー・描画・Wasm ABI接続に限る。共通のbuild.ts、server.ts、index.html、browser.js、wasm-runtime.jsはexamples/templates/wasm-grid-appに置き、アプリ固有ファイルにもdistにも複製しない。アプリ固有の生成物はgame.semantic.llang.jsonc、tests.semantic.llang.jsonc、app.json、style.css、Wasm、ビルド情報、計測結果と説明文書。

テストも同じcollection profileのJSON SemanticIRとして作り、ゲームIRをimportするテストIRからテスト用Wasmを作って実行する。初期化、全7種類の4セル、移動・壁・底・積まれたセルへの衝突、回転・キック・回転拒否、ソフト/ハードドロップ、自然落下、固定、1〜4ライン消去・得点・レベル、7-bag・再現性、次ブロック・ゴースト、一時停止・再開・終了・リセット・未知アクション・長い操作列を検証する。実装の出力をそのまま期待値に写さず、この要件から期待値を作る。

生成と修正はCodex SDKのgpt-5.6-lunaで行い、各呼び出しのreasoning設定と生イベントを保存する。初回はlow、未完成部分を段階的に仕上げる際はmediumを使う。SDK使用量は累積かどうかを実セッション記録と照合し、入力、キャッシュ入力、非キャッシュ入力、出力、合計を二重加算せず報告する。親エージェントの共通基盤整備・検証の消費量はこの計測に含まれないことを明記する。
